How “context-aware” works here

A plain scanner flags every pattern equally. AI-Sentinel parses the code, tracks whether user input (request.form, request.args, input) actually flows into the dangerous call, checks if the code sits on a Flask route, whether that route has a login check, and whether it touches passwords, payments or tokens. The risk score then goes up for reachable, public, sensitive flaws, and down for unreachable or internal ones. That is why the report is sorted by risk score, not just by bug type.

Built with Python + Flask, analysis runs locally with no external API. A clean scan means none of the checked patterns matched — it is not a guarantee of perfect security.
